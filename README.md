# 油站网点地图管理

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 营业状态流转

状态机固定为：`营业中 → 库存不足 → 补货中 →（到货确认）→ 营业中`，`营业中 ↔ 暂停营业`。

- 登记补货必须填写预计到货时间和负责人；补货中须到货确认后才能恢复营业。
- 暂停营业不能开始补货，只能恢复营业。
- 每次变更记录时间、前后状态和操作人，列表展示最近 5 条；同一处理重复点击只记一条。
